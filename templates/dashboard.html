How it works

Five automatic steps. Nobody deploys anything by hand.

  1. 1

    Open a PR

    Push a branch and GitHub Actions starts.

  2. 2

    Test & build

    Checks must pass, then a Docker image is built.

  3. 3

    Deploy

    A fresh container starts on Azure.

  4. 4

    Review

    Open the live link and see the change running.

    {% if from_ci %}You are here{% endif %}
  5. 5

    Close

    The container is deleted automatically.

Why it matters
