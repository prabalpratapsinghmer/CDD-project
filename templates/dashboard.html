How it works

Five automatic steps from pull request to cleanup. Nobody deploys by hand.

  1. 1

    Open a pull request

    Push a branch. GitHub Actions starts.

    GitHub
  2. 2

    Test & build

    Tests must pass, then a Docker image is built.

    pytest · Docker · GHCR
  3. 3

    Deploy

    A fresh container starts in Azure.

    Azure Container Instances
  4. 4

    Review

    Open the live link and see the change running.

    Link posted on the PR{% if from_ci %}You are here{% endif %}
  5. 5

    Close

    The container is deleted automatically.

    GitHub Actions
